## [https://tkmaher.github.io/fonts-index](https://tkmaher.github.io/fonts-index)

A visualization of the most popular fonts for the top ~8000 sites on the web. Sample data taken from [Majestic Million](https://majestic.com/reports/majestic-million). Fonts analyzed with [Google Fonts API](https://developers.google.com/fonts/docs/getting_started).
